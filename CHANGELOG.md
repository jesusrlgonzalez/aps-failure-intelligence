# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Security
- Browser demo (Hugging Face Space): the Python requirements are pinned (`altair==6.0.0`, `scipy==1.14.1`, `openpyxl==3.1.5`, `et-xmlfile==2.0.0`), so the code that runs next to an uploaded file no longer changes between visits.
- The demo page sets a Content-Security-Policy whose `connect-src` only allows the page itself, jsDelivr and PyPI; it also applies to the Pyodide worker.
- «Tus alertas» shows a data-use notice naming the third parties that receive the visitor's IP address (jsDelivr, PyPI, Google Fonts).

## [1.4.1] - 2026-11-17

Documentation-only correction of the P01 dossier released in 1.4.0. No code, results or evidence change.

### Changed
- `docs/pilots/P01/04_dictamen.md` now records:
  - the owner's formal acceptance of P01 (level A, approved with reservations; not an independent audit, an industrial certification, or an authorization to act on real vehicles);
  - gate G6 with its publication record;
  - reservations R1–R5 tracked in issues #9–#12;
  - the version history of the dossier.
- Package version fields (`pyproject.toml`, `aps_intel.__version__`, `CITATION.cff`) now say `1.4.1`. The `v1.4.0` tag still carries `1.3.0` in those fields; the tag is not modified.

### Unchanged
- P01 code, outputs and `evidence.json`; frozen Scania results, model and test-set evaluation.

## [1.4.0] - 2026-11-16

### Added
- Demonstration case P01 (`P01-v1.0.0`, level A, fictitious company, synthetic data): `aps_intel.pilot_p01` reconciles an export with seven documented defects (manifest checked against synthetic truth), fits the rule on closed outcomes only, issues the weekly list under a hard workshop cap with human review and suspension, compares against current practice and a type-only rule in three scenarios, and runs a cost, capacity and score-quality sensitivity. Dossier, verdict and internal self-assessed certificate in `docs/pilots/P01/`; outputs and SHA-256 evidence in `reports/pilots/P01/`, regenerated by CI.

### Unchanged
- Frozen Scania results, model and test-set evaluation.

## [1.3.0] - 2026-10-17

### Added
- MVP «Calibrador de alertas por costo» (demo mode «Tus alertas»): Excel/CSV template and row-level validation in Spanish, cost-optimal rule by risk score or by alert type (empirical-Bayes shrinkage), workshop capacity, time-split retrospective against current practice with a weekly bootstrap interval, weekly list and drift monitor (binomial load band, chi-square on the alert mix), one-page report. Pilot protocol in `docs/MVP_PILOTO.md`.
- «Señal de campo» theme and copyright footer in the demo.

## [1.2.0] - 2026-10-16

### Added
- Project page on GitHub Pages and a live demo on Hugging Face Spaces, published automatically from `main`.
- Release workflow: notes from this changelog and an evidence bundle attached to every tag.

## [1.1.0] — 2026-10-15

### Added
- Monitoring: training reference, PSI drift, binomial workshop-load band, schema and missing-data checks; `POST /monitor`.
- Stress test with eight real-world data defects (docs/09).
- Isotonic recalibration fitted on training OOF scores; `calibrated_risk` in `/score` (docs/10).

## [1.0.0] — 2026-10-15

### Added
- Byte-verified Scania APS data with the official test set sealed in code.
- Training audit, problem contract and the official cost (10 per check, 500 per missed failure).
- Nested cost cross-validation, logistic baseline, pre-registered candidates and 12-configuration tuning.
- Single final evaluation: official cost 11,540 (95 % interval 7,940–15,661), recall 95.7 %, 44.6 checks per 1,000 trucks.
- Phase-7 analysis: bootstrap uncertainty, cost-ratio sensitivity, calibration, error groups, LightGBM drivers.
- DuckDB SQL data contract, FastAPI triage service, Docker image, Streamlit decision dashboard.
- Model Card, governance files and CI (tests, dashboard, image smoke test).
